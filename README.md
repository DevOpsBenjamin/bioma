# 🌲 Bioma

> **Jeu de puzzle logique & zen sans publicité.** Harmonisez la grille en plantant un arbre par biome sans que les racines ne se touchent.

Inspiré des casse-têtes de type *Queens* / *Star Battle* (comme *Meowdoku*), repensé dans une atmosphère végétale, fluide et épurée.

---

## 🛠️ Stack & Outillage

- **Frontend** : Vue 3 (Composition API, `<script setup>`), TypeScript, Vite
- **Style** : Tailwind CSS v4, transitions fluides & design glassmorphism
- **État** : Pinia
- **Tests** : Vitest
- **PWA** : Support offline & installation mobile/desktop instantanée
- **CI / CD** : GitHub Actions (Typecheck, Vitest, Build) + Déploiement Cloudflare Pages & GitHub Pages

---

## 🚀 Commandes

```bash
# Installer les dépendances
pnpm install

# Démarrer le serveur de développement
pnpm dev

# Lancer les tests unitaires
pnpm test

# Vérifier les types TypeScript
pnpm typecheck

# Construire pour la production
pnpm build
```
